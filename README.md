**Эврика** помогает принять исследовательские работы школьников 8–11 классов и организовать их проверку: от анкеты участника до допуска ко второму этапу и выгрузки списков для оргкомитета.

Оформление сайта — «Тетрадь в клетку»: школьная эстетика, собственные шрифты и интерфейс на русском языке.

## Возможности

| Для участника | Для оргкомитета |
| :--- | :--- |
| 📝 Анкета с проверкой полей, прогрессом заполнения и черновиком в браузере | 🗂 Кабинет с заявками, поиском, секциями и заполненностью мест |
| 📎 Загрузка работы, подписанной заявки и согласия на обработку данных | ✅ Закрытие приёма и отметка допуска ко второму этапу |
| 👥 Работа с соавтором и указание научного руководителя | 📊 Выгрузки в Word, Excel и PDF; ZIP-архивы работ |
| ✏️ Изменение или удаление своей заявки, пока приём открыт | 🔗 Временные ссылки для проверяющих без контактов и СНИЛС |
| 📚 Бланки документов, направления, сроки и новости конференции | ✉️ Рассылка допущенным участникам и журнал действий |

### Как устроено участие

**Подготовить документы → заполнить анкету → получить номер заявки → дождаться решения оргкомитета.**

Текст работы принимается в **PDF, DOC, DOCX, ODT или RTF**. Подписанная заявка и согласие — в **PDF, JPG или PNG**. Презентации и видео в качестве текста работы не принимаются.

### Доступ к документам

Работы и подписанные документы выдаются через защищённые представления Django, а не по открытым ссылкам на медиафайлы. Публично доступны пустые бланки. Проверяющий получает временную ссылку на работы без контактов участников и СНИЛС; ссылку можно отключить.

## Администраторы

Главный администратор (суперпользователь) создаётся командой `createsuperuser`. Остальных он добавляет в админке:
**Пользователи → Добавить пользователя**, затем на странице пользователя отметить «Статус персонала»
и добавить группу **«Оргкомитет»**. Группа даёт доступ к заявкам, секциям и настройкам, но не к управлению пользователями.

## Локальный запуск (Windows)

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
Set-Content .env "DJANGO_DEBUG=1"
.\.venv\Scripts\python manage.py migrate
.\.venv\Scripts\python manage.py seed_demo          # демо-секции и текст, по желанию
.\.venv\Scripts\python manage.py createsuperuser    # логин в админку
.\.venv\Scripts\python manage.py runserver
```

Сайт откроется на http://localhost:8000, админка на http://localhost:8000/admin/.

Тесты: `.\.venv\Scripts\python manage.py test`

## Развёртывание на хостинге Beget

Виртуальный хостинг без Docker: Django запускается через Passenger, Python 3.12 ставится в домашний каталог через `uv`.

1. В панели Beget создать сайт и привязать к нему домен (эврика-гимназия87.рф), включить SSH-доступ.
2. Открыть «Терминал» в панели и выполнить:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/kuzmin-lemmi/Eureka/main/deploy/beget/install.sh | bash
   ```
   Скрипт склонирует проект в `~/<каталог сайта>/app`, создаст `.env` с секретным ключом,
   базу и файлы работ положит в `~/<каталог сайта>/data` (вне `public_html`).
3. Выпустить в панели бесплатный SSL-сертификат, включить переадресацию на HTTPS и создать администратора
   (команду скрипт напечатает в конце).

Обновление: `bash ~/<каталог сайта>/app/deploy/beget/update.sh`.

## Развёртывание на VPS

Подойдёт любой VPS с Ubuntu/Debian и 1 ГБ RAM. Нужен домен, A-запись которого указывает на IP сервера.

1. Установить Docker: `curl -fsSL https://get.docker.com | sh`
2. Склонировать репозиторий и создать `.env`:
   ```bash
   git clone https://github.com/kuzmin-lemmi/Eureka.git && cd Eureka
   cp .env.example .env && nano .env   # домен и DJANGO_SECRET_KEY
   ```
3. Запустить:
   ```bash
   docker compose up -d --build
   docker compose exec web python manage.py createsuperuser
   ```

Caddy сам получит и будет продлевать HTTPS-сертификат Let's Encrypt.

Обновление после изменений в репозитории:

```bash
git pull && docker compose up -d --build
```

### Резервная копия

Все данные (база и файлы работ) лежат в томе `app_data`. Архив в текущую папку:

```bash
docker compose exec web tar czf - -C /data . > backup-$(date +%F).tar.gz
```
